# 校准专科实力评分设计

## 目标

使实时医院排序能同时反映医院整体医疗能力和当前方向的直接专科依据。低等级的专科能力记录应得到体现，但不得单独压过综合能力明显更强的医院；没有检索到直接专科原文也不得将医院专科实力归零。

本设计覆盖《专科评分依据展示设计》中关于专科分计算和“暂无直接专科依据”的旧规则；专科能力依据与医院综合实力依据的展示分类保持不变。

## 适用范围

只调整实时医院搜索的 `specialty` 评分计算。保留现有五项评分详情、总分权重、医院综合实力、地理位置、资料时效与完整度、官方服务信息的计算和展示。

不定义“头部医院”名单、阈值或特殊反超限制。所有医院使用同一套函数。

## 评分模型

专科实力由医院综合实力形成基础分，再叠加当前推荐方向的直接专科证据：

```text
specialty = min(100, hospital_strength * 0.60 + specialty_evidence_bonus)
```

`hospital_strength` 采用现有医院综合实力分，即由已核验综合排名或医院公开能力得出的 `public_capability`。因此，医院整体资源和综合水平会稳定地影响每个方向的基础能力；这不是额外的排名来源。

`specialty_evidence_bonus` 只针对当前推荐科室及其标准同义词计算。普通科室目录、医院名称或不含能力级别的介绍不能获得重点学科加分。

## 证据增量

单家医院取其当前方向可验证直接证据中的最高增量，不叠加同级或低级证据。

| 直接证据 | 增量 |
| --- | ---: |
| 无直接专科能力记录 | 0 |
| 已开设当前相关科室或普通相关诊疗记录 | 2 |
| 县级重点学科、县级重点专科 | 8 |
| 市级重点学科、市级重点专科、院内临床重点专科 | 12 |
| 省级重点学科、省级重点专科、省级区域医疗中心 | 18 |
| 国家临床重点专科、国家重点专科、国家医学中心、国家区域医疗中心 | 25 |

直接的、省级或全国权威专科排名仍按现有名次与发布范围转换为专科证据增量，但其增量必须与上述规则使用同一个总上限。只有这类可比较排名，或国家级直接能力证据，才可能提供足以改变综合能力差距的专科增量。

“重点学科”必须解析其级别。含“县级”时按县级处理，不能因通用关键词“重点学科”直接取得省级分值。

## 排序语义

总分继续使用现有权重：专科实力 35%、医院综合实力 25%、地理位置 20%、资料时效与完整度 10%、官方服务信息 10%。

由于专科基础分来自全部医院通用的综合实力分，县级重点学科只会形成有限增量；同时，综合实力很强但尚未抓到本次方向直接专科原文的医院仍保有合理的专科基础分。排名高低由统一数值推导，而非按医院名称、地区或“头部医院”身份分流。

地理位置仍为本次检索范围内的推荐因素。它不改变专科证据的等级，也不得将低等级证据升级为高等级专科实力。

## 示例

以“神经内科”为例：

- 合浦县人民医院：医院综合实力 `77.3`，官网可验证“广西医疗卫生重点学科（县级）”且包含神经内科。专科实力为 `77.3 * 0.60 + 8 = 54.38`。
- 广西医科大学第一附属医院：医院综合实力 `97.0`，本次没有直接神经内科能力原文。专科实力为 `97.0 * 0.60 + 0 = 58.20`。

后者在专科基础和总分上保持领先。若前者未来出现省级或全国可比较的神经专科排名，则按统一的高等级证据增量重新计算，而非人工解除排名限制。

## 展示与错误处理

- 有直接专科证据时，继续在“专科能力依据”中显示原文级别、来源链接和核验状态。
- 无直接专科证据时，评分详情显示“暂无直接专科依据”，但专科实力数值保留由医院综合实力形成的基础分。
- 来源不可访问时，展示来源状态与现用官网入口；不可访问本身不得提升或降低证据等级。
- 不存在当前方向相关能力证据时，不能把综合排名展示为专科依据。

## 验证

后端回归测试应覆盖：

1. 综合实力 `97` 且无直接专科依据的医院，其专科分为 `58.2` 而非 `0`。
2. 综合实力 `77.3`、当前方向有县级重点学科依据的医院，其专科分为 `54.38`，低于上述医院。
3. “县级重点学科”不会命中省级或国家级增量。
4. 同方向多条证据只取最高等级，分数不叠加越界。
5. 省级/全国可比较专科排名能在总上限内提高专科分。
6. 无直接专科依据的医院仍显示“暂无直接专科依据”，且不把综合排名误标为专科依据。

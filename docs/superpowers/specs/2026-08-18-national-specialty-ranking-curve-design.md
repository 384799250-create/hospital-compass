# 全国专科排名分段曲线设计

## 目标

让全国专科排名前 100 名保持可辨识的差距，同时保留既定的 40 分排名加分上限。

## 范围

只调整全国范围的直接专科排名加分。医院综合实力形成的 60% 专科基础分、已核验专科依据分、证据只取最高值的规则，以及省市县级排名的既有范围折算均不变。

## 规则

全国直接专科排名的加分为 40 分乘以名次权重。名次从 1 至 100 时按两段线性函数计算：

```text
1 <= rank <= 20:
  weight = 1.00 - (rank - 1) * 0.30 / 19

20 < rank <= 100:
  weight = 0.70 - (rank - 20) * 0.45 / 80

rank > 100:
  weight = 0
```

因此第 1、20、100 名的排名加分分别为 `40.0`、`28.0`、`10.0`。第 20 名是两个区间的共同边界，计算结果一致。第 101 名及之后不获得全国专科排名加分。

全国排名加分仍会先经过现有的方向匹配系数：完全匹配为 `1.0`，更宽泛的相邻专科为 `0.85`，相关专科为 `0.65`。最终与官网核验的专科依据分比较，只采用其中较高者，不能叠加。

## 验证

回归测试覆盖第 1、20、21、100、101 名，确认边界连续、前 100 名严格递减、101 名归零；并验证国家级依据与排名同时存在时仍只采用最高增量。

# 青霖媒体工作台设计

## 目标

为医院指南项目增加一个独立的媒体工作台，使用青霖 Media API 生成宣传图片和视频，同时保证 API Key 只存在服务端。

## 范围

- 新增 FastAPI 青霖客户端：运行时解析 `QINGLIN_API_KEY` 或 `API_KEY`，查询模型详情与余额，提交生成任务，并轮询任务状态。
- 新增后端接口：模型列表、余额、生成任务提交、任务状态查询。
- 新增前端 `/media` 页面：切换图片/视频、选择模型、填写提示词和可选参数、提交任务、轮询并预览结果。
- 为媒体客户端和后端路由添加单元测试；前端提供 API 类型和页面渲染测试。

## 非目标

- 不修改既有就医匹配、医院排名或诊疗文案流程。
- 不把青霖密钥写入前端代码、浏览器存储、日志或提交记录。
- 不在本次任务中自动生成或上传医院项目素材。

## API 约定

服务端使用 `https://api.lk888.ai/api`，请求头为 `Authorization: Bearer <key>`。

- `GET /v1/skills/models?type=image|video`：发现可用模型。
- `GET /v1/skills/models/{model_name}`：获取模型参数定义。
- `GET /v1/skills/balance`：查询余额，生成前检查。
- `POST /v1/media/generate`：提交 `{model, prompt, params}`，成功条件为顶层 `code === 200`，返回 `data.task_id`。
- `GET /v1/skills/task-status?task_id=...`：轮询顶层 `is_final`、`state`、`result_url`、`error`。

后端统一转换成项目接口格式，并将上游错误映射为不含密钥的 HTTP 错误信息。前端只接触后端接口。

## 页面行为

页面初始加载类型为图片，加载对应模型列表和余额；切换类型重新发现模型。选择模型后读取参数定义，并根据定义渲染可选参数。提交前提示当前余额，提交后每 5 秒查询任务状态，成功显示图片或视频播放器及结果链接，失败显示可重试错误。

## 安全与可靠性

- 密钥解析顺序为进程环境 `QINGLIN_API_KEY`、`API_KEY`，再到用户环境变量，最后当前 API 项目的 `.env`。
- 未配置密钥返回 503，不显示密钥值。
- 上游请求设置超时；任务状态查询对短暂网络错误重试，前端停止轮询于最终状态。
- 余额不足时不提交生成任务。

# 收藏夹抽屉与独立页面

## 目标

让用户在任意症状搜索后仍能查看已收藏医院，并能从结果页快速打开收藏夹、取消收藏、查看医院详情。

## 交互

- 顶部导航提供“收藏夹”按钮及收藏数量。
- 点击按钮从右侧打开收藏抽屉，不清空当前搜索结果、筛选条件或滚动位置。
- 抽屉列出每家收藏医院的名称、城市、等级、地址和保存时的综合评分。
- 每项提供“查看详情”和图标化的取消收藏操作。
- 抽屉顶部的“放大查看”进入独立收藏页面；该页面使用相同列表数据，提供返回结果页操作。
- 无收藏时显示明确空状态和关闭入口。

## 数据与兼容

- 继续将收藏数据仅保存于当前浏览器的 localStorage。
- `favorites` 继续保存医院 ID，以维持当前收藏状态判断和旧数据兼容。
- 新增医院资料快照，保存 ID、名称、城市、等级、地址、综合评分、推荐科室和官网链接。
- 对旧版仅有 ID 的收藏，在抽屉打开时通过现有详情接口补齐可用公开资料；评分缺失时显示“暂无保存评分”。
- 取消收藏同时删除 ID 和对应资料快照。

## 组件边界

- `local-profile.ts` 负责收藏 ID、资料快照、迁移和本地持久化。
- 收藏夹 UI 只接收已保存资料、打开详情和取消收藏回调，不直接读写 localStorage。
- `page.tsx` 管理抽屉、独立页面和当前结果页之间的状态切换。

## 失败与边界

- 详情补齐失败时，保留收藏条目并显示医院 ID 的兜底文案，不删除用户收藏。
- 抽屉打开时没有收藏，显示空状态。
- 关闭抽屉或从独立页面返回，不触发新的医院检索。

## 验收与测试

- 收藏真实医院后，导航数量更新且抽屉出现对应条目。
- 刷新并重新进入页面后，收藏条目仍存在。
- 抽屉和独立页面均可取消收藏，并同步更新数量和列表。
- 已有的仅 ID 收藏不会被丢弃。
- 运行前端单元测试和 TypeScript 类型检查。

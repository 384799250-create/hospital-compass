# 区域切换等待反馈设计

## 目标

让用户在切换区县、市、省、全国排名范围时，清楚知道请求仍在进行、目标范围是什么，并保留当前医院列表作为可参考内容。

## 方案

采用范围条内的强状态卡，不使用遮挡医院列表的全屏或结果区覆盖层。

- 切换开始后，范围条下方出现带左侧强调色的浅色状态卡。
- 状态卡显示较大的旋转加载圈、文案“正在切换到{目标范围}排名”和“保留当前结果，新的医院范围正在刷新”。
- 范围切换按钮保持禁用，状态卡使用 `aria-live="polite"` 与 `role="status"` 宣告进度。
- 当前列表仅降低不透明度，并禁止指针操作；不移动、不清空、不替换其位置，直到新结果到达。
- 加载动画仅使用 transform 驱动的旋转，时长约 0.8 秒；在 `prefers-reduced-motion` 下停止动画并保留静态状态图形。

## 范围

仅修改结果页区域范围切换期间的状态展示和交互反馈。常规初始检索和疾病方向切换的既有加载反馈不改变。

## 验证

- 前端测试断言切换期间出现目标范围状态卡、旧列表标记为忙碌且不可交互。
- 切换完成后状态卡消失，新范围结果正常显示。
- 在桌面和窄屏下状态卡不遮挡范围按钮或列表内容。

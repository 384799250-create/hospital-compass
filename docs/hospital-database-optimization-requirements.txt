医院基础库优化要求

一、建设目标

建立可核验、可追溯、可关联的医院基础数据库，为医院筛选、区域排名、专科实力评分、核心优势和匹配理由提供唯一事实来源。
数据库必须优先服务三甲医院客户端，任何推荐结果都必须能够追溯到具体医院记录和公开证据。

二、医院主数据

每家医院必须包含：

1. 唯一医院ID，永久稳定，不得使用医院名称作为唯一主键。
2. 标准医院名称。
3. 医院别名、旧名称、简称、院区名称。
4. 医院等级：三级甲等、三级乙等、二级等。
5. 医院性质：公立、民营、部队、医学院校附属等。
6. 所属省、市、区县，必须使用统一行政区划编码。
7. 详细地址，至少包含区县、道路、门牌号；只有城市时必须标记为地址不完整。
8. 经纬度、院区信息和主院区标识。
9. 官方网站、官方挂号链接、官方联系电话。
10. 在营状态、数据更新时间、数据来源和核验状态。

三、医院与专科关联

1. 建立标准专科字典，统一“心内科、心血管内科、心脏内科”等别名。
2. 每个医院专科关联必须使用 hospital_id + department_id，禁止只用文本名称关联。
3. 记录专科名称、专科级别、重点专科类型、擅长疾病和诊疗方向。
4. 区分医院拥有的专科、医院宣传的专科和已被权威资料核验的专科。
5. 未核验、待核验、来源不明的专科不得直接作为高分证据。

四、专科实力证据

每条专科实力证据必须包含：

1. hospital_id。
2. department_id。
3. 标准专科名称。
4. 擅长疾病或诊疗范围。
5. 重点专科级别：国家级、省级、市级、区县级、院内重点等。
6. 专科榜单名称、榜单年份、榜单区域级别、医院名次。
7. 证据来源URL、来源标题、发布机构、发布日期、抓取时间。
8. 核验状态、证据有效期和失效原因。

五、区域榜单

榜单必须明确记录区域层级：

1. 全国级：权重最高。
2. 省级：低于全国级。
3. 市级：低于省级。
4. 区县级：低于市级。

同一专科、同一名次下，区域等级越高，专科实力分越高。
有明确专科排名的医院，专科分数必须高于无专科排名医院；综合医院榜单不能冒充专科榜单。

六、医院名称与专科名称标准化

1. 建立医院别名表和专科别名表。
2. 支持括号、院区、附属医院、旧名称、简称等规范化处理。
3. 导入数据时先进行名称标准化和去重，再建立关联。
4. 不得因名称相似把不同医院、不同院区或不同专科错误合并。
5. 所有别名匹配必须保留原始名称和匹配依据。

七、地址与区域准确性

1. 省、市、区县必须来自同一套行政区划字典。
2. 地址中的区县应与结构化 district 字段一致；不一致时进入质量检查。
3. 市区级排名必须要求医院具有明确区县证据，不能只知道城市就默认属于所选区县。
4. 区域证据不足时不得把区外医院混入结果。
5. 区域医院少于10家时，应提示用户切换到市级、省级或全国范围，而不是自动放宽筛选。

八、评分使用规则

1. 综合评分、医院综合实力、专科实力、地理匹配、资料完整度必须分开计算。
2. 专科实力优先使用权威专科排名和重点专科证据。
3. 无排名医院可以使用公开专科能力证据，但分数不得高于同条件下有权威排名的医院。
4. 区域匹配只能影响地理维度，不能伪造专科实力。
5. 评分结果必须输出评分依据、证据来源和数据年份。
6. 禁止为特定测试医院写单独硬编码加分规则。

九、核心优势和匹配理由数据要求

核心优势必须优先引用：专科榜单名次、重点专科级别、医疗中心资质、公开诊疗能力和专科擅长方向。

匹配理由必须说明：用户症状对应的就医方向、医院对应专科、具体证据、区域匹配结果和证据年份。

禁止只输出“综合实力强”“匹配度高”“资料完整”等无具体依据的空泛文案。

十、来源与证据管理

1. 优先级：政府及卫健委资料、医院官网、权威公开榜单、正规医疗机构目录、可信搜索结果。
2. 每条关键结论至少保留一个可访问来源。
3. 来源必须记录抓取时间和有效期。
4. 来源失效、内容变更或年份过期时进入复核队列。
5. 搜索引擎摘要只能作为候选发现依据，不能替代权威证据。

十一、数据质量检查

必须定期检查：

1. 医院ID是否重复。
2. 医院名称、别名是否冲突。
3. 省、市、区县层级是否一致。
4. 详细地址是否缺失或仅为城市名称。
5. 医院与专科是否存在无效关联。
6. 榜单名次、年份、区域级别是否缺失。
7. 证据URL是否可访问。
8. 已停业、撤销、重复和迁址医院是否正确标记。
9. 专科排名是否被错误当作医院综合排名。
10. 同一医院不同来源的地址、等级和专科信息是否冲突。

十二、推荐结果最低准入标准

医院进入推荐结果前，至少必须满足：

1. 标准医院名称已确认。
2. 医院等级已确认。
3. 省、市、区县至少有完整层级。
4. 当前区域范围与医院区域一致。
5. 至少有一个公开来源。
6. 核心优势或匹配理由能够引用具体证据；否则明确显示“暂无可靠专科证据”。

十三、实施顺序

第一阶段：整理医院主数据、唯一ID、行政区划和详细地址。
第二阶段：整理专科字典及医院-专科关联。
第三阶段：导入全国、省、市、区县级专科榜单。
第四阶段：导入重点专科和医疗中心证据。
第五阶段：建立名称匹配、证据校验和数据质量检查任务。
第六阶段：接入评分、排名、核心优势和匹配理由生成。
第七阶段：用多个省份、多个城市、多个区县进行回归测试。

十四、验收标准

1. 选择区县级范围时，结果不得出现无法证明属于该区县的医院。
2. 同专科同名次时，全国级排名分数高于省级，省级高于市级，市级高于区县级。
3. 有权威专科排名医院的专科分数高于无专科排名医院。
4. 每条核心优势和匹配理由都能追溯到来源。
5. 地址、专科、排名和医院名称在页面展示中保持一致。
6. 后端重启后，医院详情仍能从数据库恢复。
